# Asistente Contextual Corporativo: backend

La documentación completa (qué hace, arquitectura, puesta en marcha, configuración y limitaciones) está en el [README principal](../README.md).

Arranque rápido desde esta carpeta:

```bash
cp .env.example .env      # rellena GEMINI_API_KEY, ADMIN_KEY y BOOTSTRAP_ADMIN_PASSWORD
docker compose up --build # abre http://localhost:8080
```
